# KarsaStart: WordPress theme starter kit build on top TailPress.

## Spacing

- Gunakan kelipatan 4, misal .25rem/4px, .5rem/8px, .75rem/8px, dan seterusya. Tapi kelipatan 2, juga dapat digunakan jika kelipatan 4 tidak bisa memberi kesimbangan visual yang baik.

## Typography

Gunakan type scale minor third (1.200), dengan base adalah 1rem/16px dan main heading adalah 2.5rem/40px.
